# 招生推进、家访到校与报名结算设计

## 背景

中职招生流程以电话外呼为起点，按区域和学校推进。话务员负责外呼、确认意向、提交家访申请或预约到校参观；管理员负责家访、到校接待结果回填和报名确认。报名后需要明确归属到具体话务员，作为后续结算依据。

现有系统已经具备学生线索、区域/学校分配、话务员外呼、状态/阶段/意向、回访、到访、报表和操作日志能力。本设计在这些基础上补齐三个闭环：

- 家访任务闭环
- 到校参观任务闭环
- 报名归属与结算闭环

## 目标

- 让家访从备注变成可追踪任务，记录发起人、执行人、时间、地址、状态和结果。
- 让到校参观成为家访后的下一步转化动作，也允许话务员直接预约到校。
- 报名时生成稳定的报名记录，明确报名归属话务员，避免线索流转或离职导致结算混乱。
- 在学生详情中统一展示外呼、家访、到校参观、报名的时间线。
- 后续可按话务员、区域、专业、时间段统计报名和结算。

## 非目标

- 不做复杂外勤排班、地图路线和接送车辆调度。
- 不做多人分成结算；当前结算只认一个最终归属话务员。
- 不改造成完整教务或收费系统；报名金额/定金只作为可选记录。

## 角色权限

### 话务员

- 处理自己名下学生线索。
- 外呼并登记结果、意向等级、备注和回访。
- 提交家访申请。
- 直接创建到校参观预约。
- 修改自己创建且未完成的家访申请补充信息或到校预约信息。
- 查看家访结果、到校参观结果和报名归属结果。

### 管理员

- 查看所有家访任务和到校参观任务。
- 确认、安排、暂缓、取消和完成家访任务。
- 填写家访结果。
- 管理所有到校参观预约，指定接待人和调整时间。
- 填写到校参观结果。
- 确认报名、选择或修正报名归属话务员。
- 管理报名结算状态。

## 总体业务流

标准流程：

```text
导入线索
-> 按区域/学校分配
-> 话务员外呼
-> 判断意向/成绩
-> 提交家访申请
-> 管理员家访
-> 到校参观预约
-> 管理员填写参观结果
-> 报名/继续跟进/无效
```

允许的快捷流程：

```text
话务员外呼
-> 家长直接同意到校
-> 话务员创建到校参观预约
-> 管理员填写参观结果
-> 报名/继续跟进/无效
```

## 学生阶段建议

在现有阶段基础上补齐招生推进阶段。最终命名可以沿用现有中文枚举风格：

- 新线索
- 已联系
- 意向跟进
- 待家访
- 家访已安排
- 家访完成
- 待到校参观
- 到校参观已安排
- 已到校参观
- 已报名

如果暂时不想扩大阶段枚举，可以先用现有 `预约参观`、`已来访` 承接界面展示，但任务表必须保留家访和到校参观的独立状态。

## 家访任务

### 创建入口

话务员在学生详情中点击“申请家访”创建任务。提交后，学生阶段建议同步为“待家访”。

### 创建字段

- 学生
- 话务员，自动取当前用户
- 家长电话，默认带出学生档案电话
- 所在区域，默认带出学生档案区域
- 意向专业
- 中考成绩
- 平时/模拟成绩
- 家长意向说明
- 学生情况
- 是否已加微信
- 是否已和家长确认家访
- 期望家访时间
- 家访地址
- 优先级：高/中/低
- 备注

### 状态

- 待确认
- 已确认
- 已安排
- 已完成
- 已取消
- 暂缓

### 暂缓原因

- 等中考成绩
- 等家长确认时间
- 等学生本人决定
- 地址待确认
- 管理员暂不安排

### 管理员动作

- 确认家访
- 安排家访时间
- 暂缓并填写原因
- 取消并填写原因
- 完成并填写家访结果

### 家访结果

- 结果：成功/考虑中/等成绩/无效/已报名/安排到校参观
- 家长态度
- 学生态度
- 主要顾虑
- 下一步动作
- 下次跟进时间
- 是否报名
- 备注

结果联动规则：

- 选择“安排到校参观”：创建或引导创建到校参观预约，学生阶段进入“待到校参观”。
- 选择“已报名”：生成报名记录，学生状态和阶段同步为“已报名”。
- 选择“等成绩”：学生进入等成绩关注池，保留下次跟进时间。
- 选择“考虑中”：生成回访提醒给原负责话务员。
- 选择“无效”：学生状态进入无效，并记录原因。

### 微信模板复制

家访任务支持复制微信群模板：

```text
话务员：
学生姓名：
家长电话：
意向专业：
中考分数：
平时成绩：
到校参观时间：
情况：
家访时间：
地址：
```

## 到校参观任务

### 创建入口

到校参观任务可以来自两处：

- 话务员外呼后直接预约。
- 管理员填写家访结果后创建。

### 创建字段

- 学生
- 预约人：话务员或管理员
- 来源：电话外呼/家访后/管理员补录
- 关联家访任务，可为空
- 家长电话
- 所在区域
- 意向专业
- 预约到校时间
- 是否需要接送
- 来校人数
- 当前顾虑
- 接待负责人
- 备注

### 状态

- 待预约
- 已预约
- 已到校
- 未到校
- 已改期
- 已取消
- 已报名

同一个学生同一时间只能存在一个未完成的到校参观任务，避免重复邀约。

### 权限规则

- 话务员可以创建到校参观预约，也可以修改自己创建且未完成的预约信息。
- 管理员可以查看、修改和处理所有到校参观预约。
- 到校参观结果只能由管理员填写。

### 参观结果字段

- 是否到校：已到校/未到校/改期/取消
- 接待人
- 到校人数
- 参观内容：校园/宿舍/专业/实训室/费用/报名政策
- 家长态度
- 学生态度
- 当前顾虑
- 是否现场报名
- 未报名原因
- 下一步动作
- 下次跟进时间
- 备注

结果联动规则：

- 选择“现场报名”：生成报名记录，学生状态和阶段同步为“已报名”。
- 选择“未到校”：学生回到待回访，或到校任务状态为“已改期”。
- 选择“继续考虑”：生成回访提醒给当前负责话务员。
- 选择“取消/无效”：根据原因更新学生状态或保留为待跟进。

## 报名记录与结算

### 核心原则

报名记录是结算凭证，学生状态只是业务状态。线索可以重新分配，学生状态也可能被修正，但报名记录一旦生成，应稳定保存报名归属话务员、确认人、来源和操作链路。

当前结算只认一个最终归属话务员，同时保留完整过程贡献记录。

### 需要覆盖的场景

1. 原话务员离职，残留工作由新话务员继续推进并促成报名。
   - 报名归属：新话务员。
   - 原话务员外呼、备注、意向判断保留在时间线，不计最终报名结算。

2. 全程由同一个话务员跟进并促成报名。
   - 报名归属：该话务员。

3. 原话务员未接或未有效沟通，线索流转给新话务员后促成报名。
   - 报名归属：新话务员。

### 报名记录字段

- 学生
- 学生姓名快照
- 家长电话快照
- 区域快照
- 学校快照
- 意向专业
- 报名专业
- 报名时间
- 报名确认管理员
- 报名归属话务员
- 首次分配话务员
- 当前负责话务员快照
- 最后有效跟进话务员
- 来源动作：电话外呼/家访后/到校参观后/管理员补录
- 关联家访任务
- 关联到校参观任务
- 归属判定方式：自动当前负责人/自动到校预约人/自动家访申请人/手动指定
- 归属修改原因
- 报名金额/定金，可选
- 结算状态：未结算/已结算/暂缓/争议
- 结算备注
- 创建时间
- 更新时间

### 自动归属优先级

```text
1. 如果报名来自到校参观结果，默认归属到校预约人。
2. 如果报名来自家访结果，默认归属家访申请人。
3. 如果管理员直接标记报名，默认归属当前负责话务员。
4. 如果当前负责话务员为空，管理员必须手动选择。
```

保护规则：

- 如果默认归属话务员已离职或停用，系统提示管理员确认，不静默归属。
- 管理员手动修改归属时必须填写原因。
- 归属修改写入操作日志。
- 报名记录生成后，后续重新分配学生不改变报名归属。

### 结算报表

报名结算报表按报名归属话务员统计，用于发放提成或奖金。

筛选条件：

- 报名时间
- 话务员
- 区域
- 学校
- 专业
- 来源动作
- 结算状态

展示字段：

- 话务员
- 报名人数
- 已结算人数
- 未结算人数
- 暂缓/争议人数
- 学生明细
- 报名来源
- 关联家访/到校任务
- 管理员确认人

支持导出 Excel。

过程贡献报表独立展示外呼量、有效沟通、家访申请数、到校预约数和有效跟进数，用于管理分析，但不作为最终结算依据。

## 页面建议

### 话务员端

- 学生详情新增“申请家访”和“预约到校”动作。
- 待处理列表增加“待家访确认”“到校已预约”提示。
- 学生时间线展示家访申请、家访结果、到校预约、参观结果和报名记录。

### 管理员端

- 新增“家访管理”页面。
- 新增“到校参观”页面，或在工作中心新增“到校参观”队列。
- 学生详情新增“招生推进”时间线。
- 报表中心新增“报名结算”报表。

### 管理员工作中心队列

- 待确认家访
- 今日家访
- 暂缓家访
- 今日到校参观
- 未到校待处理
- 待确认报名归属
- 结算争议

## 数据边界

建议新增独立表：

- `home_visit_tasks`
- `campus_visit_tasks`
- `enrollment_records`

现有 `Visit` 表可以继续承接简单到访记录，但不建议把家访和到校参观任务都塞进同一个通用表。独立表能更清楚地表达不同权限、状态和结算链路。

所有任务和报名记录都要写入学生时间线。时间线只做聚合展示，不作为结算依据。

## 测试重点

- 话务员可以创建家访申请，管理员能在任务池看到。
- 管理员完成家访后可以创建到校参观任务。
- 话务员可以直接预约到校参观。
- 到校参观结果只有管理员可以填写。
- 现场报名会生成报名记录并同步学生为已报名。
- 离职话务员残留线索由新话务员促成时，报名归属默认新话务员。
- 未接线索流转后由新话务员促成时，报名归属默认新话务员。
- 手动修改报名归属必须填写原因并写操作日志。
- 学生后续重新分配不改变既有报名记录归属。
- 结算报表按报名归属话务员统计，而不是按当前负责话务员统计。

## 开发顺序建议

1. 后端新增家访任务、到校参观任务和报名记录模型及迁移。
2. 补齐任务创建、列表、状态更新、结果回填、报名确认 API。
3. 在学生详情聚合展示新任务时间线。
4. 话务员端增加申请家访和预约到校入口。
5. 管理员端增加家访管理和到校参观点位。
6. 报表中心增加报名结算报表和导出。
7. 补充权限、操作日志、关键业务流测试。
