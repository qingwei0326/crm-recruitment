# 趋势报表展示全部有呼出话务员设计

## 背景

趋势报表后端已经返回所选日期范围内所有话务员的每日呼出量，但前端把有呼出的话务员名单截取为前 5 名。2026-07-10 的线上只读排查确认，邹欣辰、蔡鹤楠、何银珍在默认范围内分别已有 972、949、1296 次呼出，仍因该上限没有出现在曲线和数据明细中。

## 目标

- 展示所选日期范围内所有呼出量大于 0 的话务员，不再限制为前 5 名。
- 图表曲线、图例和数据明细使用同一份话务员名单。
- 已离职话务员在所选范围内有历史呼出时继续显示；范围内呼出为 0 时隐藏。
- 在职话务员在所选范围内呼出为 0 时同样隐藏，避免无意义的零值曲线。
- 为超过 5 名的话务员提供可区分的曲线颜色。

## 非目标

- 不修改趋势报表后端接口或生产数据。
- 不改变默认日期范围、呼出量统计口径或报名统计口径。
- 不增加话务员筛选器、分页、前 5 名模式或离职状态标签。
- 不在本次改动中解决同名话务员使用姓名作为数据键的问题。

## 设计

### 展示规则

前端继续按现有逻辑遍历 `daily[].agent_calls`，累计每名话务员在所选范围内的呼出量。累计值大于 0 的全部进入 `visibleAgentNames`，累计值为 0 的全部排除。

是否显示只由当前日期范围内的呼出数据决定，不由账号是否启用决定。因此历史报表不会因为员工离职而丢失已有曲线，离职且无数据的账号也不会占用图例和表格空间。

移除 `slice(0, 5)`。`visibleAgentNames` 继续同时驱动：

- 每日呼出量对比图的曲线和图例。
- 数据明细表的话务员列及每日数值。

### 颜色

扩展 `AGENT_COLORS` 色板，使当前 8 名有呼出话务员拥有不同颜色。取色使用索引对色板长度取模，保证未来人数超过色板长度时仍能渲染，不会得到空颜色值。

### 数据流与容错

`GET /api/stats/trend` 的响应结构保持不变。缺少 `agent_calls` 的日期按空对象处理；缺少或非数值的单项按 0 处理，沿用现有容错行为。接口加载失败、空数据和日期切换行为不变。

## 测试

- 构造至少 6 名有呼出话务员，断言每个人都出现在曲线和明细表中，防止重新引入 5 人上限。
- 保留现有测试，确认所选范围内累计呼出为 0 的人员不显示。
- 运行趋势报表定向测试、前端测试、ESLint 和生产构建。
- 使用本地页面验证桌面与移动宽度下图例、曲线和横向滚动表格可用。

## 验收标准

- 线上已产生呼出的邹欣辰、蔡鹤楠、何银珍能够出现在默认趋势范围中。
- 所有有呼出人员均同时出现在图表和数据明细中。
- 已离职但范围内有历史呼出的人仍显示；范围内无呼出的人不显示。
- 不再存在固定 5 人的展示上限。
- 后端接口和数据库无改动。
