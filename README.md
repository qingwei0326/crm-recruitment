# 招生话务CRM系统

招生咨询全流程管理，支持坐席分配、通话记录、AI 意向分析、回访跟进。

## 技术栈

- **后端**: Python FastAPI + SQLAlchemy (异步) + SQLite
- **前端**: React + Vite + Tailwind CSS
- **AI**: DeepSeek API 意图分析 + 关键词兜底

## 快速启动

### Windows

双击 `start.bat` 即可启动（自动通过 WSL 拉起后端服务）。

或使用 PowerShell：

```powershell
.\start.ps1
```

### 手动启动

```bash
# 后端
uvicorn app.main:app --host 0.0.0.0 --port 8000

# 前端（开发模式）
cd frontend && npm run dev
```

## 功能

- 坐席/管理员双角色
- 学生信息 CRUD + 批量导入
- 管理员可手动新建完整学生档案，支持状态、意向等级、跟进阶段、报名信息、分配话务员和需要协助标记
- 话务员可在工作台手动添加学生，新增学生会自动分配给当前话务员
- 学生电话支持点击拨号
- AI 通话记录意向分析（A/B/C 三级）
- 回访、到访、备注全程跟踪
- 数据统计看板
- 定时备份

## 使用说明

### 管理员：手动新建学生

进入「线索管理」后点击「新建学生」。姓名和电话为必填项，其余信息可按实际情况填写，包括地域、成绩、监护人信息、学校信息、报名原因/备注、报名专业、定金、报名日期、状态、意向等级、跟进阶段、分配话务员和是否需要协助。

如果选择了「分配话务员」，系统会在创建时直接把学生分配给对应话务员；如果跟进阶段选择「已报名」，系统会同步按报名状态处理，并在未填写报名日期时使用当天日期。

### 话务员：手动添加学生

进入「今日任务」工作台后，点击右上角加号，或在移动端菜单中选择「手动添加学生」。话务员只能填写基础招生信息：姓名、电话、地域、成绩、监护人信息、学校信息和报名原因/备注。

话务员添加的学生会自动归属到当前账号，默认进入未联系、初次联系状态。话务员不能通过该入口设置分配人、报名状态、报名专业、定金、报名日期或需要协助标记。

### 点击拨号

在线索列表中点击电话列可触发系统拨号能力。是否能直接拨出取决于当前设备和浏览器是否支持 `tel:` 链接。
